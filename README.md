# Repeat Purchase Recovery

A product analytics case study focused on understanding and improving repeat purchase behaviour using cohort analysis, customer segmentation, CLV modelling, and churn signal detection.

---

## Objective

Identify the root causes of low repeat purchase rates, quantify the revenue impact, and produce actionable recommendations for a product or growth team.

---

## Tools

- **SQL** — data extraction, cleaning, aggregation
- **Python** — pandas, numpy, matplotlib
- **Jupyter** — exploratory and visual analysis
- **Power BI** — interactive dashboard
- **SQLAlchemy** — Python–database connectivity

---
